# IPL Match Outcome Prediction with AI Chatbot

This Streamlit web app predicts the winner of an IPL match using an **XGBoost** model and also includes an **AI-powered chatbot** that answers IPL-related questions.

## 🧠 Features
- Predict match winner based on teams, venue, and toss decision.
- Interactive chatbot using **Google Generative AI**.
- Clean, user-friendly Streamlit interface.

## 🚀 How to Run
```bash
pip install -r requirements.txt
python train_model.py
streamlit run ipl_dashboard.py
